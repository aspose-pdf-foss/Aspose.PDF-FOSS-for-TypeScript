# Review annotations and page-information marks

Drawing annotations support dash styles and patterns. A line's signed leader length controls which side the leaders appear on, and the appearance bounds include its leaders and endings. FreeText supports standard and embedded fonts, interior insets and cloudy borders. Link highlighting and border edits preserve the target and any existing appearance.

Page-information marks combine the caller's label, page number and optional timestamp. Use the existing mark placement modes and validate every selected page before adding the first mark. Keep the four existing mark kinds as the default selection.
