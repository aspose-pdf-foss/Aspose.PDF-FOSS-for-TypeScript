# Annotation reading order in AutoTag

Set /Tabs /S on pages with annotations. Reuse the structure writer for Link, Form (widget) and Annot roles. Attach a link to the paragraph, heading or table cell covering its anchor. Order links within a text region by their position. Append unmatched annotations in their original page order, before advancing to the next page.

Keep valid existing structure ownership during forced re-tagging and count newly tagged annotations. Annotation object references and parent-tree entries must agree after saving and reopening. Popup windows, printer marks and annotations hidden from the reader do not gain semantic elements. Use the page containing the annotation to handle an omitted /P. Compare extracted text and rendered pixels across the operation.
