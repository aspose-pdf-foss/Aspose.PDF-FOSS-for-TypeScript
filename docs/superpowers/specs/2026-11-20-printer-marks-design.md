# Printer marks

Beads issue `k4h1.4` adds trim marks, bleed marks, registration targets, and CMYK tint bars for prepress.

`page.AddPrinterMarks({ kinds?, mode?, expandCropBox? })` selects any of the four mark families. It defaults to all four as printable annotations and returns the attached handles. In content mode it appends artifact-marked graphics and returns an empty array.

The individual constructors attach one mark immediately. `TrimMarkAnnotation(page, corner)` and `BleedMarkAnnotation(page, corner)` accept `TopLeft`, `TopRight`, `BottomLeft`, and `BottomRight`. `RegistrationMarkAnnotation(page, side)` accepts `Top`, `Bottom`, `Left`, and `Right`. `ColorBarAnnotation(page, rect, channel?)` accepts a page-space rectangle and a process channel, defaulting to black. If the bar intersects the protected print area, it shifts perpendicular to its long axis to the nearest outer edge. `page.Annotations` reads `/PrinterMark` as a `PrinterMarkAnnotation` with the optional PDF `/MN` exposed as `MarkName`.

The layout works in default PDF user space. The inward edges of trim and bleed strokes align with the respective box. The strokes start outside the union of those boxes, and corner annotation rectangles can meet the finish edge. An explicit ArtBox supplies the finished boundary when TrimBox is absent. Bleed placement uses the finished boundary when BleedBox is omitted and preserves that omission for PDF/X. Registration targets use `/Separation /All` and color bars use single-channel DeviceCMYK tints. The media grows to fit the outer marks, with an implicit trim materialized when it would otherwise follow the growing crop. By default the crop also grows to show the marks in normal viewing and printing. Callers can retain their original crop with `expandCropBox: false` on the aggregate method. Page content and existing coordinates stay in place.

Both output modes use the same mark geometry and Form XObject drawing. Annotation mode makes a separate `/PrinterMark` for each mark, with a tight rectangle, a normal appearance, and Print plus ReadOnly flags. Content mode paints the same forms in an artifact scope using page-local resources. Authoring marks raises an older document's effective PDF version to 1.4. Validate options and all geometry before allocation or editing page boxes.

The user selected the aggregate method plus individual constructors for .NET parity. The aggregate method shares mark placement and can switch output formats with one option. Individual constructors allow callers to pick a corner, side, or bar rectangle directly.
