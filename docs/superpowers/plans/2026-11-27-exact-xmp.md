# Exact XMP implementation plan

Implement the [approved API](../specs/2026-11-27-exact-xmp-design.md) on the existing TypeScript document facade.

1. Add tests for filtered packets, byte ownership, empty versus absent packets, page-level aliases, scoped deletion and synchronization in both directions. Check full and incremental saves.
2. Use the existing byte-filter decoder and metadata stream writer in `src/document.ts`. Preserve raw byte order, copy at both API boundaries and detach each store independently. Carry explicit removal of a trailer Info reference through the incremental writer.
3. Document the raw and typed paths in the README and changelog. Run focused metadata and incremental tests, then verify typecheck and the full suite on main.
