# Tab Stops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tab in authored text advances to a stated stop, which may be left, right, centre or decimal, and may carry a leader. It works in `AddTextBlock`, the Flow text builders and DOCX import, and TOC rows share the leader fill.

**Architecture:** A new pure leaf, `src/tabstops.ts`, holds the vocabulary: types, validation, stop choice and leader fill. `layoutRuns` takes an optional `TabLayout`, treats a tab as its own unit whose width depends on its position on the line, and puts each tab's resolved advance on its `LaidSegment`. `stamp.ts` emits that advance as a `TJ` kern and draws leaders in a separate body. In a tagged block that body is an `/Artifact`. Flow passes the options through and, via `PlaceContext.tabOrigin`, tells the engine how far its text box sits right of the tab origin. DOCX import resolves `w:tabs` down the style chain and opts every paragraph in.

**Tech Stack:** TypeScript (strict, ESM, `.js` import specifiers), vitest, no runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-08-tab-stops-design.md`

## Global Constraints

- **Opt-in.** Without `tabStops`, every byte of output is unchanged. A tab then stays inside its word at zero width, as today.
- **Defaults.** `defaultTabInterval` defaults to 36pt. Stops are measured in points from the block's LEFT TEXT EDGE, before any paragraph or list indent.
- **One engine.** Measurement and painting both go through `layoutRuns`. There is no second tab layout anywhere.
- **Validation before any work:** every option is checked before anything is allocated or drawn. `TypeError` covers a wrong kind (non-finite, unknown name, a `decimalChar` that is not exactly one character). `RangeError` covers out-of-range values (negative position, duplicate position, interval ≤ 0).
- **Shaping.** `tabStops` together with `shape: true` throws `TypeError`.
- **Fences stay green unedited:** `rich-runs-identity`, `markdown-flow`, `html-identity`, `docx-flow-identity`, `reflow-hyphen-identity`, `flow-notes-identity`, `flow-table-notes-identity`.
- **Leaders:** `'dot'` `.`, `'middleDot'` U+00B7, `'hyphen'` `-`, `'underscore'` `_`, `'line'` (a vector rule using underline geometry), and `'none'`.
- **Tagging.** In a tagged block every leader is an `/Artifact`, drawn OUTSIDE the block's structure sequence. An artifact may not sit inside structure content (CLAUDE.md, `textrestyle.ts`).
- **Errors:** every new `catch` calls `rethrowLimit(caught)` first (`test/limits-catch.test.ts`).
- **CHANGELOG:** an entry under `## [Unreleased]` / `### Added`, ending `(v9j3.1)`.

## Review Focus

1. **A tab as the first thing on a line, with a stop at position 0.** Stops are chosen *strictly* past the pen, so the 0 stop is skipped and the next one is used. A tab at a line start must not draw zero-width. (Task 3)
2. **A right-aligned segment wider than the room before its stop.** It starts at the pen, pushing right, and wraps at its spaces if it overflows the line. It never overprints the text before the tab. (Task 3)
3. **A remainder carried to a second page or column.** The tabs in the remainder are re-resolved on the new line, and a continued paragraph lines its columns up as on page 1. (Task 4)
4. **A tab inside a linked or underlined run.** The underline spans the tab gap. The link rect covers what the run draws and stops at its last glyph, its existing rule. (Task 4)
5. **A Flow paragraph with `indent.left` and stops.** A stop at 100pt lands at 100pt from the COLUMN edge, not 100pt past the indent. (Task 5)

```ts
// src/tabstops.ts
/** Tab stops (v9j3.1): the vocabulary `layout.ts` lays tabs out by, `stamp.ts`
 *  paints leaders by and `toc.ts` counts its dot leader by. A pure LEAF
 *  importing nothing, so every rule is testable from numbers.
 *
 *  **Invariant:** a stop is chosen STRICTLY past the pen. Past the last
 *  explicit stop, it is the next multiple of the interval. A custom stop
 *  clears every default stop to its left, which is Word's rule.
 *
 *  **Invariant:** `leaderFill` is the ONE owner of how many leader glyphs fit
 *  and where they start. TOC rows and tab leaders both call it, so a dot run
 *  cannot be counted two ways. */
export type TabAlign = 'left' | 'right' | 'center' | 'decimal';
export type TabLeader = 'none' | 'dot' | 'middleDot' | 'hyphen' | 'underscore' | 'line';

/** One tab stop. */
export interface TabStop {
  /** Points from the block's left text edge, before any indent. >= 0. */
  position: number;
  /** Default 'left'. */
  align?: TabAlign;
  /** What fills the gap the tab opens. Default 'none'. */
  leader?: TabLeader;
  /** 'decimal' stops: the character aligned on the stop. Default '.'. */
  decimalChar?: string;
}

/** @internal */
export interface ResolvedTabStop { position: number; align: TabAlign; leader: TabLeader; decimalChar: string }

/** What `layoutRuns` needs. `origin` is how far the box's left edge sits
 *  RIGHT of the tab origin (a paragraph's left indent). @internal */
export interface TabLayout { stops: readonly ResolvedTabStop[]; interval: number; origin: number }

const ALIGNS: readonly TabAlign[] = ['left', 'right', 'center', 'decimal'];
const LEADERS: readonly TabLeader[] = ['none', 'dot', 'middleDot', 'hyphen', 'underscore', 'line'];

/** Validate and normalize, before anything is drawn. @internal */
export function resolveTabStops(stops: unknown, interval: unknown): { stops: ResolvedTabStop[]; interval: number } {
  if (!Array.isArray(stops)) throw new TypeError('tabStops must be an array');
  const iv = interval ?? 36;
  if (typeof iv !== 'number' || !Number.isFinite(iv)) throw new TypeError('defaultTabInterval must be a finite number');
  if (iv <= 0) throw new RangeError('defaultTabInterval must be greater than 0');
  const out: ResolvedTabStop[] = stops.map((s: unknown, i) => {
    if (typeof s !== 'object' || s === null) throw new TypeError(`tab stop ${i} must be an object`);
    const t = s as TabStop;
    if (typeof t.position !== 'number' || !Number.isFinite(t.position)) throw new TypeError(`tab stop ${i}: position must be a finite number`);
    if (t.position < 0) throw new RangeError(`tab stop ${i}: position must be >= 0`);
    const align = t.align ?? 'left';
    if (!ALIGNS.includes(align)) throw new TypeError(`tab stop ${i}: align must be one of ${ALIGNS.join(', ')}`);
    const leader = t.leader ?? 'none';
    if (!LEADERS.includes(leader)) throw new TypeError(`tab stop ${i}: leader must be one of ${LEADERS.join(', ')}`);
    const decimalChar = t.decimalChar ?? '.';
    if (typeof decimalChar !== 'string' || [...decimalChar].length !== 1)
      throw new TypeError(`tab stop ${i}: decimalChar must be one character`);
    return { position: t.position, align, leader, decimalChar };
  });
  out.sort((a, b) => a.position - b.position);
  for (let i = 1; i < out.length; i++) {
    if (out[i].position === out[i - 1].position) throw new RangeError(`two tab stops at ${out[i].position}`);
  }
  return { stops: out, interval: iv };
}

/** The stop a tab at `pen` (from the tab origin) goes to, or undefined when
 *  it lies past `right`, the line's right edge in the same frame. @internal */
export function nextStop(t: TabLayout, pen: number, right: number): ResolvedTabStop | undefined {
  let s: ResolvedTabStop | undefined = t.stops.find((x) => x.position > pen + 1e-9);
  if (s === undefined) {
    const last = t.stops.length ? t.stops[t.stops.length - 1].position : 0;
    const from = Math.max(pen, last);
    const n = Math.floor(from / t.interval + 1e-9) + 1;
    s = { position: n * t.interval, align: 'left', leader: 'none', decimalChar: '.' };
  }
  return s.position <= right + 1e-9 ? s : undefined;
}

/** The glyph a leader repeats; undefined for 'line' (a rule) and 'none'. @internal */
export function leaderGlyph(l: TabLeader): string | undefined {
  switch (l) {
    case 'dot': return '.';
    case 'middleDot': return '\u00B7';
    case 'hyphen': return '-';
    case 'underscore': return '_';
    default: return undefined;
  }
}

/** How many `glyphWidth` glyphs fit in [gapStart + clear, gapEnd - clear],
 *  RIGHT-aligned so runs line up down a column, and where the first starts.
 *  @internal */
export function leaderFill(gapStart: number, gapEnd: number, glyphWidth: number, clear: number): { count: number; x: number } {
  const end = gapEnd - clear;
  const room = end - (gapStart + clear);
  const count = glyphWidth > 0 && room > 0 ? Math.floor(room / glyphWidth) : 0;
  return { count, x: end - count * glyphWidth };
}
```

- [ ] **Step 2: CHANGELOG.** Under `### Added`:

> **Tab stops.** `tabStops` on `AddTextBlock`, Flow paragraphs, headings and list items, or once on a Flow, moves the text after a tab to a stop. A stop can be left, right, centre or decimal-aligned, and its gap can carry a leader: dots, middle dots, hyphens, underscores or a solid line. Past the last explicit stop come default stops every `defaultTabInterval` (36pt). Stops are measured from the left text edge, before any indent, as Word measures them. A stop is chosen strictly past the pen. If no stop fits on the line, the tab ends it, and a long tab segment wraps back to the margin. In justified text, word spacing stretches only after the last tab. Leaders are artifacts in tagged output, and their glyphs are counted by the same function TOC rows use, so the two agree. DOCX import now renders Word's tab stops: it resolves them down the style chain (with `clear`) and reads `w:defaultTabStop`, where every `w:tab` used to become a reported space. A tab in a table cell is still reported. Positions were checked against Word through COM. Without `tabStops`, a tab draws nothing and output is unchanged. (v9j3.1)
