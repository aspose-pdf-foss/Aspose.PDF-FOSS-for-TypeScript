# Page.Save & splitPdf Delegation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `Page.Save(options?): Uint8Array` that serializes one page to a self-contained single-page PDF, and make `splitPdf` delegate to it.

**Architecture:** Relocate the per-page `extractPage -> writeSinglePagePdf` body from `splitPdf` onto `Page.Save`. `splitPdf` becomes `doc.Pages.map(p => p.Save(options))`. `SplitOptions` becomes an alias of a new `PageSaveOptions`. A one-line `import type` change in the extractor prevents the runtime import cycle that moving extract/write into `page.ts` would otherwise create.

**Tech Stack:** TypeScript (ESM, NodeNext, strict), Vitest.

**Spec:** `docs/superpowers/specs/2026-06-04-page-save-design.md`

Add this method to the `Page` class, after the `Annotations` getter:

```ts
  /** Serialize this page to a self-contained single-page PDF. */
  Save(options: PageSaveOptions = {}): Uint8Array {
    const policy = options.prunePolicy ?? defaultPrunePolicy();
    const { objects, pageNum } = extractPage(this.doc, this.Dict, policy);
    return writeSinglePagePdf(objects, pageNum);
  }
```

- [ ] **Step 1: Rewrite `src/split.ts` to delegate**

Replace the entire contents of `src/split.ts` with:

```ts
import { Document } from './document.js';
import type { PageSaveOptions } from './page.js';

export type SplitOptions = PageSaveOptions;

/** Split a PDF into one self-contained single-page PDF per page, in page order. */
export function splitPdf(input: Uint8Array, options: SplitOptions = {}): Uint8Array[] {
  return Document.open(input).Pages.map((page) => page.Save(options));
}
```
