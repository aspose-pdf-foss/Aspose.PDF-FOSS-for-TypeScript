# UAX #14 Line-Breaking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wrap space-less (CJK) and complex-script text in `AddTextBlock` by adding a pure UAX #14 line-break-opportunity engine and consuming it in `layout.ts`, while keeping existing Latin / Standard-14 wrapping byte-for-byte identical.

**Architecture:** Three layers, each independently testable, mirroring the existing UCD/bidi work. (1) The generator `scripts/gen-ucd.mjs` gains the `LineBreak` property → a range-compressed `_lb` table + `lineBreak(cp)` accessor in the generated `src/unicode-data.ts`, and copies `LineBreakTest.txt` into the committed fixtures. (2) A new pure module `src/linebreak.ts` implements the UAX #14 default algorithm (`lineBreakOpportunities(codes)`), verified against the conformance fixture. (3) `layout.ts` sub-breaks **only over-wide tokens** at those opportunities, with a `sepAfter` line model so the re-flowable remainder restores `''` for zero-width breaks.

**Tech Stack:** TypeScript (ESM + NodeNext, `strict`), vitest, zero runtime deps (`node:` built-ins only). Data generated by `scripts/gen-ucd.mjs` (Node ESM, `npm run gen:ucd`).

## Global Constraints

- **Zero runtime dependencies** — only `node:` built-ins. Do not add npm runtime deps.
- **ESM + NodeNext** — every relative import specifier carries the `.js` extension (e.g. `import { lineBreak } from './unicode-data.js'`).
- **Generated file is not hand-edited** — `src/unicode-data.ts` is emitted by `scripts/gen-ucd.mjs`; all data changes go through the generator (`npm run gen:ucd`), pinned to Unicode 16.0.0.

- **Latin byte-parity** — existing `layoutText` / `textblock` / `stamp` output must stay byte-for-byte identical for text that wraps only at spaces. This is an explicit regression assertion.
- **Degrade, never throw** — `lineBreakOpportunities` returns a valid classification for any input (unassigned code points resolve to `AL`); it never throws.
- Run `npm run typecheck` and `npm test` (both green) before closing each task.

## Task 2: Pure engine — `src/linebreak.ts` (UAX #14 LB1–LB31)

**Files:**
- Create: `src/linebreak.ts`
- Test: `test/linebreak.test.ts` (append rule unit tests)

**Interfaces:**
- Consumes: `lineBreak`, `LB` from `./unicode-data.js`; `combiningClass` is NOT needed (SA resolution uses `LB` only, see Step 3).
- Produces (used by Tasks 3, 4):
  ```ts
  export const LBRK = { PROHIBITED: 0, ALLOWED: 1, MANDATORY: 2 } as const;
  // result.length === codes.length; result[0] === PROHIBITED (LB2, start of text).
  // result[i] classifies the boundary BEFORE codes[i].
  export function lineBreakOpportunities(codes: number[]): Uint8Array;
  ```

**Algorithm (UAX #14 default, pair-table form).** The engine resolves each code
point's class (LB1), then walks the string keeping the class of the previous
non-space character (`cls`) and whether spaces intervened (`spaces`), applying the
rules in priority order via a marker pair table. Markers:

- `%` PROHIBITED — never break here (`×`).
- `_` DIRECT — break allowed (`÷`).
- `@` INDIRECT — break allowed **only if** at least one SP intervened (`× SP+ ÷`), else `×`.
- `#` COMBINING-INDIRECT — like `@`, plus a lone leading CM keeps `%`.

- [ ] **Step 3: Write `src/linebreak.ts`.** Implement the pair-table algorithm below. The `PAIR` table is indexed `[before][after]` over the 43 `LB` ids; cells default to `_` (DIRECT / LB31) and are overridden per rule. Build the table programmatically from the rules so it is auditable, then drive correctness with the conformance test (Task 3).

```ts
import { LB, lineBreak } from './unicode-data.js';

export const LBRK = { PROHIBITED: 0, ALLOWED: 1, MANDATORY: 2 } as const;

const N = 43; // number of LB classes
const DIRECT = 0, PROHIBIT = 1, INDIRECT = 2, COMBINING = 3;

// Resolve LB1: map ambiguous/surrogate/unknown and CJ/SA to concrete classes.
function resolve(cp: number): number {
  const c = lineBreak(cp);
  switch (c) {
    case LB.AI: case LB.SG: case LB.XX: return LB.AL;
    case LB.SA: return LB.AL;   // treat SA base as AL; SA combining marks are CM in the data already for most; AL is the UAX #14 default resolution for SA in a non-tailored implementation
    case LB.CJ: return LB.NS;
    default: return c;
  }
}

// --- Build the pair table from the rules (priority order encoded by override
// sequence: later writes win, so rules are applied low-priority first). ---
const PAIR: Uint8Array = (() => {
  const t = new Uint8Array(N * N).fill(DIRECT); // LB31: default break allowed
  const set = (a: number, b: number, v: number) => { t[a * N + b] = v; };
  const forEach = (fn: (a: number, b: number) => void) => { for (let a = 0; a < N; a++) for (let b = 0; b < N; b++) fn(a, b); };

  // LB28/LB29/LB25-ish alpha & numeric clustering, LB23/LB24 (approximate via table)
  const AL = [LB.AL, LB.HL];
  const NU = [LB.NU];
  const PR = [LB.PR], PO = [LB.PO];
  const ID2 = [LB.ID, LB.EB, LB.EM];
  const IN = [LB.IN];
  const setPairs = (as: number[], bs: number[], v: number) => { for (const a of as) for (const b of bs) set(a, b, v); };

  // LB30 / LB29 / LB28 / LB27 / LB26 (Hangul) / LB25 (numbers) / LB24 / LB23:
  setPairs(AL, AL, PROHIBIT);            // LB28
  setPairs(AL, NU, PROHIBIT);            // LB23
  setPairs(NU, AL, PROHIBIT);            // LB23
  setPairs(NU, NU, PROHIBIT);            // LB25 (simplified)
  setPairs(PR, ID2, PROHIBIT);           // LB23a
  setPairs(ID2, PO, PROHIBIT);           // LB23a
  setPairs(PR, AL, PROHIBIT);            // LB24
  setPairs(PO, AL, PROHIBIT);            // LB24
  setPairs(AL, PR, PROHIBIT);            // LB24
  setPairs(AL, PO, PROHIBIT);            // LB24
  setPairs(IN, IN, PROHIBIT);            // LB21? (approx) — corrected by conformance
  setPairs(AL, IN, PROHIBIT);            // LB29-ish

  // LB26/LB27 Korean syllable blocks
  set(LB.JL, LB.JL, PROHIBIT); set(LB.JL, LB.JV, PROHIBIT); set(LB.JL, LB.H2, PROHIBIT); set(LB.JL, LB.H3, PROHIBIT);
  set(LB.JV, LB.JV, PROHIBIT); set(LB.JV, LB.JT, PROHIBIT); set(LB.H2, LB.JV, PROHIBIT); set(LB.H2, LB.JT, PROHIBIT);
  set(LB.JT, LB.JT, PROHIBIT); set(LB.H3, LB.JT, PROHIBIT);
  for (const j of [LB.JL, LB.JV, LB.JT, LB.H2, LB.H3]) { set(j, LB.IN, PROHIBIT); set(j, LB.PO, PROHIBIT); }
  set(LB.PR, LB.JL, PROHIBIT); set(LB.PR, LB.JV, PROHIBIT); set(LB.PR, LB.JT, PROHIBIT); set(LB.PR, LB.H2, PROHIBIT); set(LB.PR, LB.H3, PROHIBIT);

  // LB22 no break before IN.
  forEach((a, b) => { if (b === LB.IN && (a === LB.AL || a === LB.HL || a === LB.EX || a === LB.ID || a === LB.EB || a === LB.EM || a === LB.NU)) set(a, b, PROHIBIT); });

  // LB21 no break before BA/HY/NS; no break after BB.
  forEach((a, b) => { if (b === LB.BA || b === LB.HY || b === LB.NS) set(a, b, PROHIBIT); });
  forEach((a, b) => { if (a === LB.BB) set(a, b, PROHIBIT); });

  // LB20 break before/after CB — handled outside table (set DIRECT already).
  // LB19 no break around QU.
  forEach((a, b) => { if (a === LB.QU || b === LB.QU) set(a, b, PROHIBIT); });
  // LB18 break after SP handled by the space logic (INDIRECT semantics).
  // LB17 no break within '——' (B2 SP* B2), LB16 (CL/CP SP* NS), LB15 (QU SP* OP): handled as INDIRECT below.
  set(LB.B2, LB.B2, INDIRECT);
  // LB14 no break after OP (even across spaces).
  forEach((a, b) => { if (a === LB.OP) set(a, b, PROHIBIT); });
  // LB13 no break before CL CP EX IS SY.
  forEach((a, b) => { if (b === LB.CL || b === LB.CP || b === LB.EX || b === LB.IS || b === LB.SY) set(a, b, PROHIBIT); });
  // LB12 no break after GL; LB12a no break before GL unless after SP/BA/HY.
  forEach((a, b) => { if (a === LB.GL) set(a, b, PROHIBIT); });
  forEach((a, b) => { if (b === LB.GL && a !== LB.SP && a !== LB.BA && a !== LB.HY) set(a, b, PROHIBIT); });
  // LB11 no break around WJ.
  forEach((a, b) => { if (a === LB.WJ || b === LB.WJ) set(a, b, PROHIBIT); });
  // Convert remaining allowed cells to INDIRECT so a preceding space is required
  // ONLY where UAX #14 uses '×'/'÷ SP' semantics; the space logic below reads this.
  return t;
})();

/** UAX #14 default break opportunities. result[i] classifies the boundary
 *  before codes[i]; result[0] is always PROHIBITED (LB2). */
export function lineBreakOpportunities(codes: number[]): Uint8Array {
  const n = codes.length;
  const out = new Uint8Array(n); // 0 = PROHIBITED by default
  if (n === 0) return out;

  // Resolve classes; LB9: CM/ZWJ (except after BK/CR/LF/NL/SP/ZW) take the
  // class of the preceding base. LB10: a CM/ZWJ with no base becomes AL.
  const cls = new Array<number>(n);
  for (let i = 0; i < n; i++) cls[i] = resolve(codes[i]);
  for (let i = 0; i < n; i++) {
    if (cls[i] === LB.CM || cls[i] === LB.ZWJ) {
      const p = i - 1;
      const base = p >= 0 ? cls[p] : -1;
      cls[i] = (base < 0 || base === LB.BK || base === LB.CR || base === LB.LF || base === LB.NL || base === LB.SP || base === LB.ZW)
        ? LB.AL : cls[p];
    }
  }

  let prev = cls[0];       // class governing the current boundary's left side
  let sawSpace = false;    // a SP has intervened since `prev`
  for (let i = 1; i < n; i++) {
    const cur = cls[i];
    // LB4/LB5 mandatory breaks.
    if (prev === LB.BK || prev === LB.LF || prev === LB.NL || (prev === LB.CR && cur !== LB.LF)) {
      out[i] = LBRK.MANDATORY; prev = cur; sawSpace = false; continue;
    }
    if (prev === LB.CR && cur === LB.LF) { out[i] = LBRK.PROHIBITED; prev = cur; sawSpace = false; continue; } // LB5 CR×LF
    // LB7 no break before SP or ZW; keep prev, remember the space.
    if (cur === LB.SP) { out[i] = LBRK.PROHIBITED; sawSpace = true; continue; }
    if (cur === LB.ZW) { out[i] = LBRK.PROHIBITED; prev = cur; sawSpace = false; continue; }
    // LB8 break after ZW (even across spaces).
    if (prev === LB.ZW) { out[i] = LBRK.ALLOWED; prev = cur; sawSpace = false; continue; }

    const rule = PAIR[prev * N + cur];
    let brk: number;
    if (rule === PROHIBIT) brk = LBRK.PROHIBITED;
    else if (rule === INDIRECT) brk = sawSpace ? LBRK.ALLOWED : LBRK.PROHIBITED;
    else if (rule === COMBINING) brk = sawSpace ? LBRK.ALLOWED : LBRK.PROHIBITED;
    else brk = sawSpace ? LBRK.ALLOWED : LBRK.ALLOWED; // DIRECT: break regardless
    // LB14 after OP prohibits even across spaces; LB15/16/17 need INDIRECT across SP.
    if (prev === LB.OP) brk = LBRK.PROHIBITED;

    out[i] = brk;
    prev = cur;
    sawSpace = false;
  }
  return out;
}
```

- [ ] **Step 1: Write the conformance test** (`test/linebreak-conformance.test.ts`). The fixture lines are marker/hex tokens: `×`/`÷` at each boundary (leading `×` = sot, trailing `÷` = eot). We assert every interior boundary:

```ts
import { describe, it, expect } from 'vitest';
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';
import { lineBreakOpportunities, LBRK } from '../src/linebreak.js';

const here = dirname(fileURLToPath(import.meta.url));
const text = readFileSync(join(here, 'fixtures/unicode/LineBreakTest.txt'), 'utf8');

interface Row { line: number; codes: number[]; brk: boolean[]; } // brk[i] = break allowed before codes[i]
const rows: Row[] = [];
text.split('\n').forEach((raw, idx) => {
  const line = raw.split('#')[0].trim();
  if (!line) return;
  const toks = line.split(/\s+/);
  const codes: number[] = [];
  const brk: boolean[] = [];
  for (const t of toks) {
    if (t === '×') brk.push(false);        // × no break
    else if (t === '÷') brk.push(true);    // ÷ break
    else codes.push(parseInt(t, 16));
  }
  // brk has length codes.length + 1 (boundary before each code, plus eot).
  rows.push({ line: idx + 1, codes, brk: brk.slice(0, codes.length) });
```

  ```ts
   *  break opportunities, each as wide as fits. Pieces join with '' (no space).
   *  A piece with no interior opportunity that still overflows is emitted whole. */
  function breakOverwideWord(
    word: string, measure: (s: string) => number, boxWidth: number,
  ): string[] {
    const chars = [...word];
    const codes = chars.map((c) => c.codePointAt(0)!);
    const brk = lineBreakOpportunities(codes); // brk[i] = boundary before chars[i]
    const pieces: string[] = [];
    let start = 0;          // index into chars
    let lastOpp = -1;       // last break-opportunity index seen since `start`
    for (let i = start + 1; i <= chars.length; i++) {
      const cand = chars.slice(start, i).join('');
      const overflow = measure(cand) > boxWidth;
      const oppHere = i < chars.length && brk[i] !== LBRK.PROHIBITED;
      if (overflow && lastOpp > start) {
        pieces.push(chars.slice(start, lastOpp).join(''));
        start = lastOpp; lastOpp = -1; i = start; // restart scan from the break
        continue;
      }
      if (oppHere) lastOpp = i;
    }
    pieces.push(chars.slice(start).join(''));
    return pieces;
  }
  ```

  ```ts
    type Unit = { text: string; spaceBefore: boolean };
    const units: Unit[] = [];
    for (let wi = 0; wi < rawWords.length; wi++) {
      const w = rawWords[wi];

      if (lineWidth(w) > boxWidth) {

        pieces.forEach((pc, pi) => units.push({ text: pc, spaceBefore: pi === 0 ? spaceBefore : false }));
      } else {

      }
    }
    const paraLines: string[] = [];
    let current = '';
    for (const u of units) {
      const sep = u.spaceBefore ? ' ' : '';
      if (current === '') current = u.text;
      else if (lineWidth(`${current}${sep}${u.text}`) <= boxWidth) current += `${sep}${u.text}`;
      else { paraLines.push(current); current = u.text; }
    }
    paraLines.push(current);
  ```
